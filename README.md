# 熊貓救援隊：四邊形秘境

香港小四四邊形關係的七關探究網站。GitHub Pages提供學生及老師畫面，共用伺服器保存課堂進度、答案和老師開關。

## 目前狀態

已準備可部署的GitHub Pages前端及完整伺服器原始碼，儲存庫目前為私人。公開發布仍需擁有人確認。同步伺服器目前亦維持私人存取；不會把平台存取憑證放入前端。

## 網站內容

學生直接選4A–4C及學號1–25／小組1–6；七關包括鄰邊對邊、工具調查、長方形與正方形、菱形與正方形、平行四邊形、家族分類、救援總任務。每關完成後，須老師主動開啟下一關。

老師介面驗證密碼後，使用12小時的伺服器登入憑證查看進度及操作關卡。密碼只設定於伺服器，不包含在程式碼或建置檔中。

## 檔案

- `src/`：GitHub Pages React前端。
- `site/`：已建置的靜態網站，含獨立分頁入口。
- `server-source/`：現有Sites/Vinext伺服器完整原始碼、結構遷移及測試，沒有學習紀錄、密碼或平台服務憑證。
- `.github/workflows/build.yml`：只檢查建置，不自動公開發布。

## 建置

`npm install`，然後`npm run build`。網站基底路徑為`/panda-quadrilateral-rescue/`。

## 待發布的最後設定

確認公開發布後：開放Pages網站及儲存庫；同步伺服器允許GitHub Pages來源`https://wongngaiyam3-rgb.github.io`跨來源請求，再開放平台存取。老師API仍需老師登入憑證，學生個人紀錄仍需各自的通行碼。

GitHub Pages本身不執行伺服器程式。請勿把老師密碼、平台服務存取憑證或學生資料加入此儲存庫。
