# 熊貓救援隊：四邊形秘境

香港小四四邊形關係課的七關探究網站。學生先操作，再收集證據並解釋；老師主動開啟下一關。

- `/`：直接選班別、學號／組別，加入該班最新的課堂；通行碼恢復進度。
- `/map`：七關任務地圖。
- `/quest/1` 至 `/quest/7`：鄰邊對邊、工具調查、長方形與正方形、菱形與正方形、平行四邊形、集合分類、綜合救援。
- `/journal`：發現手冊。
- `/teacher`：教師控制台、班級進度、匿名討論、CSV匯出。

## 執行與資料

保留 Sites/Vinext 的平台身分和建置整合。D1 綁定為 `DB`；依序套用 `drizzle/` 的結構遷移。`TEACHER_PASSWORD` 在部署環境設定為秘密，不存入原始碼。教師授權由伺服器 sessions 驗證；密碼驗證後，把隨機登入憑證保留於目前分頁的 sessionStorage（儲存不可用時使用記憶體），以 x-teacher-session 標頭傳送，支援 Cookie 被阻擋的瀏覽器或內嵌頁面。既有 HttpOnly cookie 仍可驗證。憑證有效12小時，登出即撤銷，密碼不儲存在瀏覽器。學生以裝置通行碼存取各自的紀錄；資料庫只存通行碼的SHA-256摘要。

教學網站新版本維持原來的私人存取範圍，除非擁有人要求變更。公開部署後仍需教師密碼才能讀取全班紀錄或操作關卡。

學生草稿約每秒同步，老師開關約每3秒同步；斷線時顯示尚未保存。學生只能進入老師已開放且已完成前一關的頁面，伺服器在每次寫入再次檢查。七關答案由伺服器驗證；老師可以明確標記下一個未完成關卡。

## 驗證

`node node_modules/typescript/bin/tsc --noEmit`

API 整合測試在記憶體 SQLite 執行，不需要啟動伺服器。透過 esbuild 把 `app/api/classroom/route.ts` 的 `cloudflare:workers` 替換為 `tests/env.mjs`，輸出 `.sites-runtime/route-test.mjs`，再執行 `node tests/classroom.mjs`。測試環境只使用虛構密碼。

目前已驗證七關正確答案、錯誤重試、老師密碼、草稿保存、老師逐關解鎖、暫停、不同課堂隔離、老師標記與報表。尚未進行瀏覽器畫面／觸控操作驗證。

內嵌繁體字型以 Noto Sans CJK TC 子集提供，字型依 SIL Open Font License 1.1 授權。日系標題採用裝置可用的明朝體；內文優先使用圓體／日系黑體並提供繁體字型備援。

API 讀取會辨別平台 HTML 登入頁、非 JSON 回應及 JSON API 錯誤。登入失效時提供平台重新登入連結；連線恢復後清除舊錯誤，保留裝置通行碼與已存的學習紀錄。
